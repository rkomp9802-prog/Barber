## Запуск

Нужен Node.js 22.12+.

```bash
npm install
```

```bash
npm run dev
```

- Сайт: http://localhost:3000, запись: http://localhost:3000/book.
- Без API сайт показывает демо-данные из `apps/web/src/data`.

Демо-режимы страницы записи:

- `/book?service=<id услуги>` — услуга уже выбрана (id из `GET /api/v1/services`);
- `/book?barber=<id барбера>` — барбер уже выбран (так ведут кнопки «Записаться» в карточках барберов);
- `/book?demo=error` — показать состояние ошибки при загрузке времени.

### API (нужна база)

1. Скопируйте `apps/api/.env.example` в `apps/api/.env` и заполните `DATABASE_URL` и `DIRECT_URL` из Supabase.
2. Один раз сгенерируйте Prisma Client:

   ```bash
   npm run db:generate -w @barber/api
   ```

3. Запустите API:

   ```bash
   npm run dev:api
   ```

   API откроется на http://localhost:4000 (проверка: http://localhost:4000/health).

Миграции и тестовые данные: `npm run db:migrate -w @barber/api`, затем `npm run db:seed -w @barber/api`.
Seed создаёт первого администратора по `ADMIN_LOGIN` и `ADMIN_PASSWORD` из `.env`.

Резервная копия данных: `npm run db:backup -w @barber/api`. Каждая таблица сохраняется в JSON в `backups/<дата-время>/`.
В копии есть имена и телефоны клиентов, поэтому папка `backups/` в `.gitignore`: храните её только у себя.

### Админка

- Вход: http://localhost:3000/admin/login, панель: http://localhost:3000/admin.
- Чтобы войти, нужен администратор из seed и запущенный API.

### Mini App (по желанию)

```bash
npm run dev -w @barber/miniapp
```

Mini App откроется на http://localhost:5174. Внутри Telegram она работает только после настройки бота и HTTPS-адреса.

### Подтверждение номера через Telegram

Онлайн-запись принимается только с номером, который клиент подтвердил в Telegram кнопкой «Поделиться номером».

- **Сайт.** Запись создаётся со статусом «ждёт подтверждения» (`pending`), время держится 10 минут. Клиент открывает бота по ссылке, делится номером, и запись подтверждается. Если в Telegram другой номер, в запись попадает номер из Telegram. Не подтвердил за 10 минут — время освобождается.
- **Mini App.** При первой записи нужно поделиться номером, дальше запись подтверждается сразу.
- **Только номера Узбекистана (+998).** Клиенты без Telegram или с иностранным номером записываются по телефону, запись создаёт администратор в админке.
- Бот принимает только собственный контакт отправителя: пересланный или чужой контакт не подтверждает номер.
- Барбер получает уведомление только после подтверждения.
- Лимиты: не больше 3 подтверждённых предстоящих записей на номер и не больше 3 неподтверждённых с одного IP.
- Без настроенного бота (локальная разработка) запись с сайта сразу подтверждена.

## Проверки

```bash
npm run test       # unit-тесты всех пакетов (Vitest)
npm run typecheck  # проверка типов во всех пакетах
npm run build      # production-сборка сайта
```

- Интеграционный тест записи (`apps/api/test/integration/booking-db.test.ts`) запускается только с `TEST_DATABASE_URL`. Без неё он пропускается. Таблицы в тестовой базе очищаются, поэтому используйте отдельную базу.
- Тесты Edge Function: `npm run test:functions`.
- E2E (Playwright, `apps/web/e2e`): запись и отмена через сайт, двойная запись и перенос через API. Тестовые записи отменяются в конце.
  По умолчанию идут на `localhost:3000` и `localhost:4000`; на другой адрес — через `E2E_BASE_URL` и `E2E_API_URL`.
  Запускайте из папки с точным регистром имени (`Barber`), иначе Playwright загрузит модули дважды и не найдёт тесты.
